**33. 다음 점을 $x$축의 방향으로 3만큼, $y$축의 방향으로 4만큼 평행이동한 점의 좌표를 구하시오.**

  

  

(1) $(4, -5)$

  

  

- $(4+3, -5+4) = (7, -1)$
    
    (2) $(-1, -3)$
    
      
    
      
    
- $(-1+3, -3+4) = (2, 1)$
    
      
    

**34. 점 $(a,-1)$을 $x$축의 방향으로 1만큼, $y$축의 방향으로 $b$만큼 평행이동한 점의 좌표가 $(2,6)$일 때, 두 상수 $a, b$의 값을 각각 구하시오.**

  

  

- $a + 1 = 2 \implies a = 1$
    
      
    
- $-1 + b = 6 \implies b = 7$
    
      
    

**35. 원 $x^2 + y^2 + 4x - 8y + 11 = 0$을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동하였더니 원 $(x-1)^2 + (y-2)^2 = 9$가 되었다. 이때 두 상수 $a, b$의 값을 각각 구하시오.**

  

  

- $x^2 + y^2 + 4x - 8y + 11 = 0 \iff (x+2)^2 + (y-4)^2 = 9$
    
      
    
- 중심 $(-2, 4) \to (1, 2)$
    
      
    
- $-2 + a = 1 \implies a = 3$
    
      
    
- $4 + b = 2 \implies b = -2$
    
      
    

**36. 직선 $y=ax+b$를 $x$축의 방향으로 1만큼, $y$축의 방향으로 -2만큼 평행이동하면 직선 $x-3y+1=0$과 $y$축에서 수직으로 만난다. 이때 두 상수 $a, b$의 값을 각각 구하시오.**

  

  

- $x - 3y + 1 = 0 \iff y = \frac{1}{3}x + \frac{1}{3}$, $y$절편 $(0, \frac{1}{3})$
    
      
    
- 수직 조건: $a \times \frac{1}{3} = -1 \implies a = -3$
    
      
    
- 평행이동한 직선: $y - (-2) = -3(x - 1) + b \implies y = -3x + b + 1$
    
      
    
- 점 $(0, \frac{1}{3})$ 대입: $\frac{1}{3} = b + 1 \implies b = -\frac{2}{3}$
    
      
    

**37. 오른쪽 그림과 같이 두 점 $(0,2)$, $(2,0)$과 원점을 지나는 원의 방정식을 $f(x,y)=0$이라고 할 때, 방정식 $f(x-m,y-n)=0$이 나타내는 도형은 방정식 $f(x,y)=0$이 나타내는 도형과 외접한다. 이때 $m^2+n^2$의 값은?**

  

  

- 세 점 $(0,0), (2,0), (0,2)$를 지나는 원: $(x-1)^2 + (y-1)^2 = 2$, 중심 $(1,1)$, 반지름 $r = \sqrt{2}$
    
      
    
- 외접 조건: 중심 사이의 거리 $d = r + r = 2\sqrt{2}$
    
      
    
- 이동한 원의 중심: $(1+m, 1+n)$
    
      
    
- $\sqrt{m^2 + n^2} = 2\sqrt{2} \implies m^2 + n^2 = 8$
    
      
    

**38. 다음 점을 $x$축, $y$축, 원점, 직선 $y=x$에 대하여 대칭이동한 점의 좌표를 각각 구하시오.**

  

  

(1) $(3, 4)$

  

  

- $x$축: $(3, -4)$
    
      
    
- $y$축: $(-3, 4)$
    
      
    
- 원점: $(-3, -4)$
    
      
    
- 직선 $y=x$: $(4, 3)$
    
      
    

(2) $(5, -1)$

  

  

- $x$축: $(5, 1)$
    
      
    
- $y$축: $(-5, -1)$
    
      
    
- 원점: $(-5, 1)$
    
      
    
- 직선 $y=x$: $(-1, 5)$
    
      
    

(3) $(-2, 3)$

  

  

- $x$축: $(-2, -3)$
    
      
    
- $y$축: $(2, 3)$
    
      
    
- 원점: $(2, -3)$
    
      
    
- 직선 $y=x$: $(3, -2)$
    
      
    

**39. 다음 방정식이 나타내는 도형을 $x$축, $y$축, 원점, 직선 $y=x$에 대하여 대칭이동한 도형의 방정식을 각각 구하시오.**

  

  

(1) $x-2y+1=0$

  

  

- $x$축: $x + 2y + 1 = 0$
    
      
    
- $y$축: $-x - 2y + 1 = 0 \iff x + 2y - 1 = 0$
    
      
    
- 원점: $-x + 2y + 1 = 0 \iff x - 2y - 1 = 0$
    
      
    
- 직선 $y=x$: $y - 2x + 1 = 0 \iff 2x - y - 1 = 0$
    
      
    

(2) $(x-2)^2 + (y-3)^2 = 4$

  

  

- $x$축: $(x-2)^2 + (y+3)^2 = 4$
    
      
    
- $y$축: $(x+2)^2 + (y-3)^2 = 4$
    
      
    
- 원점: $(x+2)^2 + (y+3)^2 = 4$
    
      
    
- 직선 $y=x$: $(x-3)^2 + (y-2)^2 = 4$
    
      
    

**40. 다음 그림과 같이 두 점 $A(6,2)$, $B(3,-1)$과 직선 $y=x$ 위를 움직이는 점 $P$에 대하여 $\overline{AP}+\overline{BP}$의 최솟값을 구하시오.**

  

  

- $A(6,2)$를 직선 $y=x$에 대칭이동한 점: $A'(2,6)$
    
      
    
- $\overline{AP} + \overline{BP} = \overline{A'P} + \overline{BP} \ge \overline{A'B}$
    
      
    
- $\overline{A'B} = \sqrt{(3-2)^2 + (-1-6)^2} = \sqrt{1 + 49} = \sqrt{50} = 5\sqrt{2}$
    
      
    

**41. 함수 $y=f(x)$의 그래프가 오른쪽 그림과 같을 때, 함수 $y=f(-x)$, $y=-f(-x)$, $x=f(y)$의 그래프로 둘러싸인 도형의 넓이를 구하시오.**

  

  

- 기본 영역(삼각형)의 넓이: $\frac{1}{2} \times 2 \times 1 = 1$
    
      
    
- $x$축 및 $y$축 대칭형으로 구성되는 전체 마름모 넓이: $4 \times 1 = 4$
    
      
    

**42. 원 $x^2+y^2=9$, $(x-2)^2+(y+4)^2=9$가 직선 $ax+by+5=0$에 대하여 대칭일 때, 두 상수 $a, b$의 합 $a+b$의 값을 구하시오.**

  

  

- 원의 중심: $(0,0)$, $(2,-4)$
    
      
    
- 두 중심의 중점: $(1, -2)$
    
      
    
- 중점 대입: $a(1) + b(-2) + 5 = 0 \implies a - 2b = -5$
    
      
    
- 두 중심을 잇는 직선의 기울기: $\frac{-4-0}{2-0} = -2 \implies$ 대칭축의 기울기: $\frac{1}{2}$
    
      
    
- $-\frac{a}{b} = \frac{1}{2} \implies b = -2a$
    
      
    
- $a - 2(-2a) = -5 \implies 5a = -5 \implies a = -1$
    
      
    
- $b = 2$
    
      
    
- $a + b = -1 + 2 = 1$
    
      
    

**43. 좌표평면 위의 두 원 $C_1: (x-2)^2+(y-6)^2=1$, $C_2: (x-6)^2+(y-4)^2=9$에 대하여 원 $C_1$ 위를 움직이는 점 $P$, 원 $C_2$ 위를 움직이는 점 $Q$, $x$축 위를 움직이는 두 점 $R, S$가 있다. 두 점 $R, S$를 $y$축에 대하여 대칭이동한 점을 각각 $R', S'$이라 할 때, <보기>에서 옳은 것만을 있는 대로 고른 것은?**

  

  

- 점 $R(r,0)$, 대칭점 $R'(-r,0)$
    
      
    
- **ㄱ. $A(4,2), A'(4,-2)$일 때 $\overline{AR}=\overline{A'R'}$**
    
      
    
      
    - $\overline{AR} = \sqrt{(r-4)^2 + 4}$
        
          
        
    - $\overline{A'R'} = \sqrt{(-r-4)^2 + 4} = \sqrt{(r+4)^2 + 4} \ne \overline{AR}$ (거짓)
        
          
        
- **ㄴ. 점 $A(4,2)$에 대하여 $\overline{AR}+\overline{PR'}$의 최솟값은 9이다.**
    
      
    
      
    - $C_1$의 중심 $(2,6)$을 $y$축 대칭이동한 원 $C_1'$의 중심: $(-2,6)$, 반지름: $1$
        
          
        
    - $\overline{AR} + \overline{PR'} \ge \sqrt{(-2-4)^2 + (6+2)^2} - 1 = \sqrt{36+64} - 1 = 10 - 1 = 9$ (참)
        
          
        
- **ㄷ. 점 $B(a, 6a+1)$ ($a$는 양의 상수)에 대하여 $(\overline{BR}+\overline{PR'}\text{의 최솟값}) = (\overline{BS}+\overline{QS'}\text{의 최솟값}) + 2$일 때, $\overline{OB}$의 값은 $\frac{\sqrt{65}}{2}$이다.**
    
      
    
      
    - $B(a, 6a+1)$을 $x$축 대칭이동한 점: $B'(a, -6a-1)$
        
          
        
    - $C_1$의 $y$축 대칭 중심 $O_1'(-2,6)$, 반지름 $1 \implies$ 최솟값: $\overline{B'O_1'} - 1$
        
          
        
    - $C_2$의 $y$축 대칭 중심 $O_2'(-6,4)$, 반지름 $3 \implies$ 최솟값: $\overline{B'O_2'} - 3$
        
          
        
    - $(\overline{B'O_1'} - 1) = (\overline{B'O_2'} - 3) + 2 \implies \overline{B'O_1'} = \overline{B'O_2'}$
        
          
        
    - $(a+2)^2 + (-6a-7)^2 = (a+6)^2 + (-6a-5)^2$
        
          
        
    - $37a^2 + 88a + 53 = 37a^2 + 72a + 61 \implies 16a = 8 \implies a = \frac{1}{2}$
        
          
        
    - $B\left(\frac{1}{2}, 4\right) \implies \overline{OB} = \sqrt{\left(\frac{1}{2}\right)^2 + 4^2} = \sqrt{\frac{1}{4} + 16} = \frac{\sqrt{65}}{2}$ (참)
        
          
        
- **정답: ㄴ, ㄷ**
