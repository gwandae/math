### 21번

**문제**

  

  

다음 원의 방정식을 구하시오. (1) 중심이 점 $(-1,3)$이고 반지름의 길이가 $4$인 원 (2) 중심이 원점이고 점 $(3,4)$를 지나는 원

  

**풀이**

(1)

$(x+1)^2 + (y-3)^2 = 16$

  

  

(2)

$r^2 = 3^2 + 4^2 = 25 \implies x^2 + y^2 = 25$

  

  

### 22번

**문제**

  

  

다음 방정식이 나타내는 원의 중심의 좌표와 반지름의 길이를 각각 구하시오. (1) $(x-3)^2+(y+2)^2=49$ (2) $x^2+y^2-8x+10y+5=0$

  

**풀이**

(1)

중심: $(3, -2)$, 반지름: $7$

  

  

(2)

$(x-4)^2 + (y+5)^2 = 4^2 + (-5)^2 - 5 = 36$

중심: $(4, -5)$, 반지름: $6$

  

  

### 23번

**문제**

  

  

방정식 $x^2+y^2+4x-2y+k=0$이 원을 나타내도록 하는 실수 $k$의 값의 범위를 구하시오.

  

**풀이**

$(x+2)^2 + (y-1)^2 = 5-k$

  

  

$5 - k > 0 \implies k < 5$

  

  

### 24번

**문제**

  

  

중심이 직선 $y=x+4$ 위에 있고 점 $(-2,4)$를 지나는 두 원이 각각 $x$축에 접할 때, 이 두 원의 반지름의 길이의 합을 구하시오.

  

**풀이**

중심: $(a, a+4)$

  

  

$x$축 접: $(x-a)^2 + (y-a-4)^2 = (a+4)^2$

  

  

점 $(-2, 4)$ 대입:

$(-2-a)^2 + (-a)^2 = (a+4)^2$

  

  

$a^2 - 4a - 12 = 0 \implies (a+2)(a-6) = 0 \implies a = -2 \text{ 또는 } 6$

  

  

$r_1 = \vert{}-2+4\vert{} = 2$, $r_2 = \vert{}6+4\vert{} = 10$

  

  

$r_1 + r_2 = 12$

  

  

### 25번

**문제**

  

  

임의의 실수 $a$에 대하여 원 $x^2+y^2+2ax-6ay+10a-25=0$의 넓이의 최솟값을 구하시오.

  

**풀이**

$(x+a)^2 + (y-3a)^2 = 10a^2 - 10a + 25$

  

  

$r^2 = 10\left(a - \frac{1}{2}\right)^2 + \frac{45}{2} \ge \frac{45}{2}$

  

  

최솟값 = $\frac{45}{2}\pi$

  

  

### 26번

**문제**

  

  

다음 원과 직선의 위치 관계를 말하시오. (1) $x^2+y^2=2$, $y=-x-3$ (2) $(x-2)^2+(y+1)^2=5$, $x-2y=5$

  

**풀이** (1) $d = \frac{\vert{}3\vert{}}{\sqrt{1^2+1^2}} = \frac{3}{\sqrt{2}} = \frac{3\sqrt{2}}{2}$, $r = \sqrt{2}$ $d > r \implies$ 만나지 않는다.

  

(2) $d = \frac{\vert{}2 - 2(-1) - 5\vert{}}{\sqrt{1^2+(-2)^2}} = \frac{1}{\sqrt{5}}$, $r = \sqrt{5}$ $d < r \implies$ 서로 다른 두 점에서 만난다.

  

### 27번

**문제**

  

  

원 $x^2+y^2=9$와 직선 $2x-3y-a=0$이 접할 때, 양수 $a$의 값을 구하시오.

  

**풀이**

$d = \frac{\vert{}-a\vert{}}{\sqrt{2^2+(-3)^2}} = \frac{a}{\sqrt{13}} = 3 \quad (a > 0)$

  

  

$a = 3\sqrt{13}$

  

  

### 28번

**문제**

  

  

원 $x^2+y^2-2x+4y=0$과 직선 $x+2y-k=0$이 만나도록 하는 실수 $k$의 값의 범위를 구하시오.

  

**풀이**

$(x-1)^2 + (y+2)^2 = 5 \implies$ 중심: $(1,-2)$, $r = \sqrt{5}$

  

  

$d = \frac{\vert{}1+2(-2)-k\vert{}}{\sqrt{1^2+2^2}} = \frac{\vert{}k+3\vert{}}{\sqrt{5}} \le \sqrt{5}$

  

  

$\vert{}k+3\vert{} \le 5 \implies -8 \le k \le 2$

  

  

### 29번

**문제**

  

  

원 $x^2+y^2=25$ 위의 점 $(3,4)$를 지나는 접선을 $l$이라고 하자. 이 원에 접하고 직선 $l$에 수직인 직선의 방정식을 구하시오.

  

**풀이**

$l: 3x+4y=25 \implies m = -\frac{3}{4}$

  

  

수직인 직선의 기울기: $m' = \frac{4}{3}$

  

  

$y = \frac{4}{3}x \pm 5\sqrt{\left(\frac{4}{3}\right)^2 + 1} = \frac{4}{3}x \pm \frac{25}{3}$

  

  

### 30번

**문제**

  

  

원 $x^2+y^2-2x-4y=0$의 넓이가 두 직선 $y=ax$와 $y=bx+c$에 의하여 4등분될 때, 세 상수 $a, b, c$의 곱 $abc$의 값을 구하시오.

  

**풀이** 중심 $(1, 2)$에서 두 직선이 직교 $y = ax \implies 2 = a(1) \implies a = 2$ $y = bx+c \implies ab = -1 \implies b = -\frac{1}{2}$ $2 = -\frac{1}{2}(1) + c \implies c = \frac{5}{2}$ $abc = 2 \times \left(-\frac{1}{2}\right) \times \frac{5}{2} = -\frac{5}{2}$

  

### 31번

**문제**

  

  

점 $A(2,1)$과 원 $x^2+y^2+4x+2y+1=0$ 위의 점 $P$를 이은 선분 $AP$의 중점을 $M$이라고 하자. 이때 점 $M$과 직선 $3x+4y-10=0$ 사이의 거리의 최솟값은?

  

**풀이** 원 $C$: $(x+2)^2 + (y+1)^2 = 4$ (중심: $(-2, -1)$, 반지름: $R=2$) $M$의 자취: 중심: $C'\left(\frac{2-2}{2}, \frac{1-1}{2}\right) = (0, 0)$, 반지름: $r = \frac{R}{2} = 1$ $(0, 0)$과 직선 $3x+4y-10=0$ 사이의 거리: $d = \frac{\vert{}-10\vert{}}{\sqrt{3^2+4^2}} = 2$ 최솟값 = $d - r = 2 - 1 = 1$

  

### 32번

**문제**

  

  

원 $O$가 $x$축과 두 점 $A, B$에서 만나고, $y$축과 두 점 $C, D$에서 만난다. 네 점 $A, B, C, D$와 원 $O$가 다음 조건을 만족시킬 때, 사각형 $ABCD$의 넓이를 구하시오. (단, 점 $A$의 $x$좌표는 점 $B$의 $x$좌표보다 작고, 점 $C$의 $y$좌표는 점 $D$의 $y$좌표보다 작다.) (가) 선분 $AB$를 $1:4$로 내분하는 점은 선분 $CD$의 중점이다. (나) 원 $O$가 직선 $4x-3y+13=0$에 접한다.

  

**풀이**

내분점과 중점의 일치점: 원점 $O(0,0)$

  

  

$A(-a, 0), \quad B(4a, 0) \quad (a > 0)$

  

  

$x$축이 선분 $CD$의 수직이등분선이므로 선분 $AB$는 지름 중심: $\left(\frac{3}{2}a, 0\right)$, 반지름: $R = \frac{5}{2}a$ 접선 거리 조건: $d = \frac{\left\vert{}4\left(\frac{3}{2}a\right) - 3(0) + 13\right\vert{}}{\sqrt{4^2+(-3)^2}} = \frac{6a+13}{5} = \frac{5}{2}a$ $12a + 26 = 25a \implies 13a = 26 \implies a = 2$ $\overline{AB} = 5a = 10$ $c = \sqrt{R^2 - \left(\frac{3}{2}a\right)^2} = \sqrt{5^2 - 3^2} = 4 \implies \overline{CD} = 8$ $S = \frac{1}{2} \times \overline{AB} \times \overline{CD} = \frac{1}{2} \times 10 \times 8 = 40$
